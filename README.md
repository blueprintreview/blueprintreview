# BlueprintReview

The Blueprint viewer and diff for Unreal Engine, no editor needed.

BlueprintReview opens Unreal Engine Blueprint `.uasset` files outside the editor: event graphs, functions, variables, components and defaults, drawn the way the Blueprint editor draws them. It compares two versions of a Blueprint side by side, and works as a `git difftool` and a P4V diff tool.

It reads uncooked editor assets saved by UE 4.26, 4.27 and 5.0 onwards.

- Downloads: [Releases](https://github.com/blueprintreview/blueprintreview/releases) (Windows first)
