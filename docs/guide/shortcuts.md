# Keyboard and mouse

## Anywhere

| Keys | Does |
|---|---|
| <kbd>F1</kbd> | Opens this guide |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | *Find* in the open Blueprint |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | *Find in Blueprints*, across the open folder |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Shows or hides the *Explorer* (folder mode) |
| <kbd>Ctrl</kbd>+<kbd>`</kbd> | Shows or hides the *Output Log* |
| <kbd>Alt</kbd>+<kbd>Left</kbd> / <kbd>Alt</kbd>+<kbd>Right</kbd> | Back / forward, after a jump or a search result (the mouse's back and forward buttons too) |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> | Everything larger / smaller / back to 100% |
| <kbd>Ctrl</kbd>+scroll, over a panel | Everything larger or smaller |
| <kbd>Enter</kbd>, in a search box | Searches |

## In a graph

| Keys or mouse | Does |
|---|---|
| Right-drag, or left-drag on a node | Pans |
| Scroll | Zooms, up to 1:1 |
| <kbd>Ctrl</kbd>+scroll | Zooms in past 1:1, as in the editor |
| <kbd>F</kbd> or <kbd>Home</kbd> | Fits the graph to the view |
| Click | Selects a node; on empty space, clears the selection |
| <kbd>Shift</kbd>+click / <kbd>Ctrl</kbd>+click | Adds a node to the selection / toggles it |
| Left-drag on empty space | Selects with a box: with <kbd>Shift</kbd> it adds, with <kbd>Alt</kbd> it removes, with <kbd>Ctrl</kbd> it toggles |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Selects every node |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copies the selected nodes, to paste into the editor ([Copy nodes](copy-nodes.md)) |
| Double-click a node | Opens what it calls: a function, macro or collapsed graph, in this or another Blueprint |
| Right-click | *Copy* and *Select All* |

## In Time-lapse

| Keys | Does |
|---|---|
| <kbd>Left</kbd> / <kbd>Right</kbd>, with the pointer over the bar | The older / newer revision |

## In lists and trees

| Mouse | Does |
|---|---|
| Double-click a *Find* result | Jumps to it |
| Double-click a row with children | Opens or closes it |
| Right-click a *My Blueprint* item | *Copy* (a variable or a function, to paste into *My Blueprint* in the editor) |
| Right-click a *Details* row | *Copy* the value, *Copy Display Name*, *Copy Internal Name* |
